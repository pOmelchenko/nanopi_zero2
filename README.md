# NanoPi Zero2

Практическая документация для NanoPi Zero2 / RK3528: подготовка ОС,
аппаратные интерфейсы, подключение SPI-дисплея ILI9341 и тачскрина XPT2046,
диагностика и восстановление. Репозиторий работает самостоятельно.

## Начать работу

| Задача | Документ |
| --- | --- |
| Подключить дисплей и тачскрин, сверить 30-pin FPC | [Аппаратный справочник](docs/reference/hardware.md) |
| Включить SPI1 и проверить дисплей/тач на официальной Ubuntu | [FriendlyElec Ubuntu 24.04](docs/guides/ubuntu-spi.md) |
| Подготовить resource.img вручную на NanoPi | [Нативная сборка DTB](docs/guides/resource-image.md) |
| Проверить дисплей на указанной сборке Armbian | [Armbian SPI](docs/guides/armbian-spi.md) |
| Найти причину сбоя или восстановить загрузку | [Диагностика и восстановление](docs/guides/troubleshooting.md) |
| Сверить ОС, ядро, диапазоны тача и результаты | [Проверенные конфигурации](docs/reference/validation/README.md) |

**Перед подключением:** сигнальные линии — 3.3 V; провода переставлять при
отключённом питании. RESET — FPC23, DC — FPC25. FPC24 и линии 19/20/21
`gpiochip4` заняты регуляторами питания: запрос этих GPIO может остановить плату.
Полная схема и предупреждения находятся в аппаратном справочнике.

## Проверенная конфигурация

| Вариант | Результат и границы проверки |
| --- | --- |
| FriendlyElec Ubuntu 24.04.3, kernel `6.1.141 #27`, eMMC | Основной маршрут: ILI9341 на `/dev/spidev1.0`, XPT2046 через `ads7846`, совместная работа после перезагрузки |
| Armbian 26.8 rolling, Debian 13, kernel `6.18.41-current-rockchip64` | SPI и ILI9341 на `/dev/spidev0.0` проверены для этой сборки; тач и актуальное сквозное развёртывание не квалифицированы |
| Полные eFlasher-образы Ubuntu / Debian 13 FriendlyElec | Сборочные процедуры описаны в [разработке](docs/development/README.md); сборка полного Ubuntu-образа и аппаратный запуск Debian не выполнены |

Дисплей — `2.8" TFT 240xRGBx320 V1.1`. Результаты относятся к указанным
версиям и экземпляру панели. Отдельные проверки установщика, восстановления
и длительной работы с тачем перечислены в разделе разработки.

## Структура репозитория

```text
docs/
  guides/                          процедуры с указанной аппаратной проверкой
  reference/                       распиновка, загрузка, инструменты, результаты
  vendor/                          каталог официальных источников
  development/                     незавершённые сборки и квалификация
tools/
  target/                          Linux-скрипты и overlay для самой NanoPi
  dependencies/friendlyelec-kernel/ версии исходников и патчи vendor DTS
  SHA256SUMS                       контрольные суммы скриптов, overlay и патчей
```

[Каталог документации](docs/README.md) связывает руководства со справочником,
официальными источниками и работами в разработке. Образы ОС, бэкапы и результаты
прогонов хранятся вне отслеживаемых файлов.

## Инструменты

Локальные пути в командах разрешаются от корня репозитория. Для подготовленной
официальной Ubuntu и подключённого по схеме дисплея с тачем:

```bash
scp tools/target/enable_spi1.sh pi@192.168.1.88:/home/pi/
ssh -t pi@192.168.1.88 \
  'sudo bash /home/pi/enable_spi1.sh --touch --install --reboot'
```

Без `--touch` устанавливается только дисплей. Перед записью подготовить UART
или recovery/microSD по [руководству Ubuntu](docs/guides/ubuntu-spi.md).
Требования, режимы и проверка целостности: [справочник инструментов](docs/reference/tools.md).

```bash
git clone https://github.com/pOmelchenko/nanopi_zero2.git
cd nanopi_zero2
```

Рабочая процедура содержит применимую конфигурацию, команды, проверяемый
результат и способ восстановления. [Раздел разработки](docs/development/README.md)
