# Проверенные конфигурации NanoPi Zero2

Результаты относятся к указанным образам и дисплею
`2.8" TFT 240xRGBx320 V1.1`. Они задают границы применимости руководств.
Незавершённые проверки перечислены в [разработке](../../development/README.md).

## FriendlyElec Ubuntu — физическая проверка 2026-08-01

| Параметр | Конфигурация |
| --- | --- |
| SBC | FriendlyElec NanoPi Zero2 / RK3528 |
| ОС | Ubuntu 24.04.3 LTS, `ubuntu-noble-core-arm64`, arm64 |
| Ядро | `6.1.141`, FriendlyElec build `#27` |
| Python | 3.12.3; libgpiod 2.2.1 в venv |
| Накопитель | eMMC 233 GiB; раздел `resource` определялся по PARTLABEL |
| Kernel source | `221af17f44d3b513b53b694d5b41614e53c5ab1b` |
| Дисплей | SPI1 CS0, `/dev/spidev1.0`, 1 MHz; RESET FPC23, DC FPC25 |
| Тач | SPI1 CS1, `ads7846`, `ADS7846 Touchscreen`, в этом прогоне `/dev/input/event2` |
| IRQ | FPC4 / GPIO4_A4, active low |

### Результат дисплея и DTB

| Этап | Статус |
|---|---|
| Инвентаризация голой Ubuntu 24.04.3 | Выполнена по SSH |
| SPI1 в исходном DTB имеет `disabled` | Проверено на работающей плате |
| GPIO4 соответствует `/dev/gpiochip4` | Проверено на работающей плате |
| Vendor patch применяется к kernel tree | Проверено через `git apply` |
| Python-скрипт с `--bus 1 --reset 0` | Проверено на дисплее |
| Нативная сборка DTB и `resource.img` на NanoPi | Выполнена |
| Загрузка изменённого `resource.img` | Выполнена, `/dev/spidev1.0` создан |
| Вывод тестовой таблицы и кириллицы | Выполнен на 1 MHz |
| Проверка SSH и `dmesg` после вывода | Выполнена, ошибок нет |
| Сборка полного eFlasher Ubuntu image | Не выполнена |

### Результат совместной работы с XPT2046

- Дисплей на CS0 работает при активном `ads7846` на CS1.
- Ядро выдаёт X `0..3550`, Y `350..3650`, pressure `0..2000`, BTN_TOUCH press/release.
- Точные нажатия на пять экранных мишеней дали максимум линейной ошибки `2.1 px`.
- IRQ-счётчик не изменился за пять секунд без касаний (`delta=0`).
- После контрольной перезагрузки дисплей и input-устройство поднялись вместе.

Device Tree и коэффициенты конкретного экземпляра:
[справочник дисплея и тача](../display-and-touch.md). Пяти-точечный прогон
не заменяет длительную нагрузку и расширенную калибровку.

## Armbian — ограниченная физическая проверка

Armbian 26.8 rolling, Debian 13 Trixie, Linux
`6.18.41-current-rockchip64`, пакетный python3-libgpiod 2.2.1.
Подтверждены SPI1 как `/dev/spidev0.0`, тестовая таблица ILI9341 и UTF-8.
Точная дата прогона не зафиксирована в исходном описании. Touch и повторное
сквозное развёртывание на обновлённом rolling-образе не квалифицированы.
Armbian Ubuntu с venv описан как вариант; отдельной актуальной аппаратной
проверки нет. Процедура: [Armbian SPI](../../guides/armbian-spi.md).

## Сборочные варианты без аппаратного результата

| Часть | Статус |
|---|---|
| Распиновка и ILI9341 | Проверены на Armbian и официальной Ubuntu 24.04 |
| Vendor DTS и kernel config | Подтверждены исходниками FriendlyElec |
| Patch к `rk3528-nanopi-rev01.dts` | Проверен через `git apply` |
| `sd-fuse_rk3528` для Debian | Соответствует официальному маршруту |
| Совместимость Debian 13 с libgpiod 2.2.1 | Подтверждена пакетами Debian |
| Загрузка изменённого официального Debian | Не выполнена |
| Вывод картинки на официальном Debian | Не выполнен |

Полный eFlasher-образ Ubuntu не собран. Отдельные прогоны установщика
с тачем, recovery, повторной калибровки и длительной нагрузки остаются
в [разработке](../../development/README.md). Статус готового маршрута
на них не распространяется.
